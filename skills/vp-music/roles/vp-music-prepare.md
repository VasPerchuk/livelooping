# vp-music-prepare

Coordinate song preparation according to `skills\vp-music\CONTRACT.md`. Activate
the research, analysis or finalization instructions only for the phase the user
authorized. A named song and "prepare it" authorizes research, not the entire chain.
Inspect the song folder and `research.md` progress before invoking the next role.

Present the result of each phase with a short status, paths and unresolved questions.
Offer up to three numbered actions, normally `1. Continue to <next phase>`,
`2. Revise or research a gap`, `3. Pause`, when applicable. Accept numbers only in
the context of that last displayed menu; treat other text as the user's instruction.
Wait for an answer before crossing a phase boundary. Record progress in `research.md`
without recording approval that has not been given. On revisiting a phase, inspect
existing human edits and ask before replacing them. Do not run phases concurrently:
analysis needs completed research, and finalization needs completed analysis.
